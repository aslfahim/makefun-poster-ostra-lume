OSTRA LUME — a travel poster for a city of pearl towers that stands in the
sea at low tide and is an island again by morning. One Node program paints
it from raw pixels: a moonlit teal night, a huge low moon, a spiral pearl
lighthouse sweeping its beam over the water, a cluster of smaller pearl
towers, and the whole city mirrored with a ripple in the wet sand and tide
pools below. The city's name is set in hand-drawn stroke letters in
pearl-white across the top dark. It writes one PNG to /output/entry.png.

## Run it

```sh
node main.ts
```
